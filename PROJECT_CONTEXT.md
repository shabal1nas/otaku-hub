Anime discovery platform.

## Current Stage

Frontend MVP with static mock data and production-like architectural goals.

Already implemented:

- home page layout
- hero section
- anime sliders
- top ranked block
- sidebar navigation
- right panel
- mobile navigation

Planned next:

- anime details page
- browse page
- search page
- my list page
- API integration
- async UI states

## Planned Features

- anime catalog
- anime details page
- search
- filters
- favorites
- my list
- top ranked
- trending
- recommendations

- authentication
- user profile

Anime API.

Current limitation:

- real API is not connected yet

## UI Goals

- clean modern design
- responsive layout
- desktop-first approach with mobile support
- accessible interactions
- stable visual structure before API integration

## Engineering Goals

- production-like frontend practices
- maintainable FSD structure
- typed domain models
- clear separation between UI and data preparation
- minimal but clean abstractions

## Project Purpose

- portfolio project
- learning modern frontend
- demonstrating production-ready thinking without unnecessary enterprise complexity
